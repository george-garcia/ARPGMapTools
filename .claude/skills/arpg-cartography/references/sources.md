# Sources: how to cite, and where every source is listed

Every rule in this skill cites the research finding behind it; each research file ends with its own numbered source list
(URLs, authors, dates read, limits). Cite as below, and never attribute a claim to a studio, developer or scientist unless
the source says it.

Rule prefixes in this skill: **G** geography (`geography.md`), **K** craft (`cartography-craft.md`), **H** world to zones
(`world-to-zones.md`), **M** and **TG** Azgaar and tool gaps (`azgaar-ops.md`), **GA** Gaea (`gaea.md`), **P** George's decisions.

**Known limits of the research** (each file has its own "Limits" or caveats): some scientific sources were read as
abstracts only (A: Kleinhans 2013, Gasse 1977, Wang 2018, Langbein 1961; Dallol figures second-hand); Worldbuilding Stack
Exchange was read through a mirror without vote counts, the Cartographers' Guild and GDC Vault weren't reachable, and the
Breath of the Wild "triangle" rule is known only second-hand (B); poe2db was read through a summarising fetch and no videos
were re-watched (C). Rules resting on these say so in their tag.
